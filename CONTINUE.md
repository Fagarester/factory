# Factorio native (bionic) — состояние на 2026-11-17

Цель: официальный Linux ARM64 Factorio в процессе bionic, рендер напрямую на GLES, без мостов.
GitHub (с 2026-11-19): https://github.com/Fagarester/factory (публичный, MIT, master → origin/main), последний релиз v0.206 (2026-11-27, коммит d741736: логи вырезаны, исправления, разделение GameActivity); до него v0.203 (2026-11-26, коммит a93bfed; v0.202 удалён по просьбе пользователя, сообщение его коммита переписано force push, копия старой истории /root/factorio-native-before-reword-70d43f7.bundle; до него v0.196, v0.195, v0.136, v0.127, v0.126, v0.125, v0.113).

## Проверено в proot на телефоне (Adreno 830, offscreen)
- loader/: загрузчик (pread в анонимную память, релокации, 294 TLS-трамплина, shim glibc->bionic).
  --version, --create, --benchmark; сумма симуляции 2m_final.zip = glibc (716673159).
- fnsdl/: SDL_DYNAPI_entry (GL-атрибуты -> ES 3.2, GetProcAddress, SwapWindow: FPS+снимки),
  fngl.c: функции драйвера GLES напрямую + адаптеры (GetString/GetIntegerv/расширения,
  ShaderSource 330->320 es, ClearDepth/DepthRange/DrawBuffer, LOD_BIAS, GetTexImage,
  compressed size/readback), заглушки с логом для отсутствующих функций.
- Главное меню и загруженная карта рисуются правильно, 60 FPS; GPU-сжатие проходит самопроверку.

## Запуск приложения (с v0.47)
- Иконка: игра сразу (папка из prefs "launcher" gamePath + доступ к файлам). Иначе FirstRun (из /root/factory):
  поиск (GameSource.findFolder: Download/factorio, Download 3 уровня, корень 2 уровня, ≤4 с) → найдено: запуск;
  нет → архив в Download → распаковка в Download/factorio[-N]; нет → экран «Где игра?» (layout game_source из Factory:
  папка / архив tar.xz / демо с factorio.com). Игра не копируется, запускается из папки.
- Настройки (бывший лаунчер) — ярлык «Настройки» при удержании иконки (dynamic shortcut, EXTRA_OPEN_SETTINGS).
- .nomedia в папке игры при каждом запуске (галерея не показывает текстуры).

## План Vulkan (nvk) — что осталось и почему (2026-11-24, после 0.145)
Сохранено: всё только на диске (с v0.136 не закоммичено, GitHub — по команде). Снимок: work/snapshots/
vulkan-0.145-20261124.tar.gz (патч + 16 новых файлов; копия в Download/FNative-snapshot-vulkan-0.145-20261124.tar.gz).

Сделано: один рендер Vulkan = nvk (мост удалён, 0.142); ETC2 внутри игры на Mali (0.138); glCopyImageSubData — mip
атласов, кнопки и иконки (0.143); кэш конвейеров на диск (0.144); кэш атласов игры под nvk настоящими блоками,
glReadPixels (0.145). Всё проверено только в proot на Adreno 830.

Осталось, по порядку:
1. Проверка 0.143–0.145 на телефонах (Adreno и 9300+): меню/инвентарь, два запуска с кэшем, замер 2m_final.
   Почему первым: все исправления nvk сделаны вслепую по proot; на Mali nvk с прямым ETC2 ещё не мерили ни разу.
2. Замер nvk на Mali с журналами (threads.log/prof.log). Почему: на 9300+ в OpenGL ES поток симуляции занят лишь
   ~50–60 % — упор, вероятно, в ГП/драйвер GLES; от этого замера зависит, что из п.3–6 даст больше.
3. [сделано в 0.147] Апскейл и масштаб рендера в nvk (GSR/билинейный). Почему: при упоре в ГП это самый
   большой рычаг — 75 % разрешения = ~56 % пикселей.
4. Pre-rotation (поворот кадра самим nvk). Почему: present всё время SUBOPTIMAL, поворачивает система — лишний
   проход композиции полного кадра на каждый кадр (на Mali заметнее).
5. Меньше LOAD цвета на тайловом ГП: 7–17 загрузок полного буфера на кадр (меню, proot). Почему: каждая — чтение
   всего изображения из памяти; нужен анализ, какие буферы игра перерисовывает целиком (риск сломать картинку).
6. ЦП-сторона nvk: динамические смещения UBO + кольцо, дескрипторы только изменённые; на Mali без push descriptors.
   Почему ниже: в proot сам nvk ~1 % ЦП потока рендера, драйвер ~9 %.
7. Пробелы: StagingBitmap (игра пока не вызывает), glReadPixels не-RGBA, копии GPU-BC в ETC2 на Mali (пропускаются
   намеренно), SPIR-V кэш (~0,4 с при старте). Почему низко: в меню/загрузке/игре не встречались.
8. [0.151: отладка FNGL_LOG_BT/FNGL_DIRECT_STATS убрана] решить про NVK_TRACE-хуки.
